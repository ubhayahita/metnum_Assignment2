Masalah yang diangkat dari bidang Biomedical Engineering: farmakokinetik 4 kompartemen, kondisi STEADY STATE saat infus kontinu.
Kompartemen: 1 = plasma (darah), 2 = hati, 3 = otot, 4 = otak.
Neraca massa tiap kompartemen (dA_i/dt = 0):  M A = R
  A = jumlah obat (mg), R = laju infus (mg/jam), M dibangun dari konstanta laju (1/jam).
